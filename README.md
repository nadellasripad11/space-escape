# omega-7

a figma escape room for hack club's wrong tool. you wake up alone on a dying space station and have to find the escape pod before the oxygen runs out. play it in figma present mode.

**play it live in your browser: https://nadellasripad11.github.io/space-escape/site/** (real-time 3d, synthesized sound, a real oxygen timer, the same puzzles). the figma version has a button that links to it.

the rooms are real 3d scenes (three.js, lit and shadowed, rendered in headless chrome) placed into figma as images. everything you click is a live figma layer on top: hotspots, hud, keypad, wiring, hints. every frame and prototype link is generated by script.

## build it in figma (free, no mcp needed)

1. `node tools/build-plugin.js` (writes `plugin/code.js`, the committed one already works)
2. in figma desktop: plugins > development > import plugin from manifest > `plugin/manifest.json`
3. run "OMEGA-7 builder". it makes a new page with 41 frames, wires the prototype and checks the win screen is reachable
4. select the title frame and press present

## solution (spoilers)

crew 8 x deck 7 = pin 56, then wires red > triangle, blue > square, yellow > circle.

## the 3d pipeline

- `render3d/scenes/*.js` one three.js scene per room (quarters, control, pod, title, space, podsprite), `kit.js` shared materials/textures/post, `podmodel.js` the lifeboat
- `node render3d/render-all.js` renders every scene to `render3d/out` (needs `npm install` inside `render3d/` and chrome installed)
- every render also records where each named 3d object lands on screen, so figma hotspots line up with the props
- `node tools/build-assets.js` packs the renders (`assets/`) and regions into `src/assets.js`, then `node tools/build-plugin.js`

## layout

- `src/` figma builders: `rooms.js` `puzzles.js` `closeups.js` `endings.js`, shared `helpers.js` `images.js` `art.js` `ui.js` `flow.js`, `wire.js` for the prototype links
- `tools/` build scripts and the offline test harness
- `assets/` the rendered images
- `web-prototype/` the first html version of the puzzle logic

## testing without figma

`node tools/mock-figma.js [outDir] [--sheet frameKey ...]` runs the plugin against a small fake of the figma api, plays through the prototype links (solution, wrong pins, wrong wires, hints, close-ups) and can render frames to png (`HOT=1` outlines the hotspots). needs `npm install` inside `tools/` once.

## oxy, the mascot

a little face-only buddy with four moods (idle, happy, worried, dizzy). `node tools/mascot.js` generates `assets/mascot/*.svg` plus the data files used by the website and the figma plugin. he greets you on the title screen, helps in the mission checklist and hint cards, and reacts on the win and lose screens.
