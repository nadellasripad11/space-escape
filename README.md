# omega-7

a space escape room i built inside figma for hack club's wrong tool. you wake up alone on a dying station with the oxygen draining and you have to work through five puzzles to reach the escape pod. you play it in figma present mode, just clicking around the rooms like an old point and click game.

**play it live in your browser: https://nadellasripad11.github.io/space-escape/site/** (real 3d, synthesized sound, a running oxygen timer, same puzzles). the figma version has a button that links to it.

the rooms are actual 3d scenes (three.js, lit and shadowed, rendered in headless chrome) dropped into figma as images. everything you click is a live figma layer sitting on top: hotspots, the hud, the keypad, the wiring, the hints. every frame and every prototype link is generated by a script so i never had to wire 160 hotspots by hand.

## the five puzzles

1. find the keycard in the locker
2. read the captain's log and decode the reactor sequence (nato phonetic)
3. crack the airlock pin on the terminal
4. restart the reactor by flipping the switches in the right order
5. rewire the escape pod, then launch

## build it in figma (free, no mcp needed)

1. `node tools/build-plugin.js` (writes `plugin/code.js`, the committed one already works)
2. in figma desktop: plugins > development > import plugin from manifest > `plugin/manifest.json`
3. run "omega-7 builder". it makes a fresh page with 48 frames, wires the whole prototype, and checks the win screen is actually reachable
4. select the title frame and press present

## solution (spoilers)

- airlock pin: crew x deck. the roster shows 8 crew, the sign shows level 2, so the pin is 16.
- reactor: the captain's log spells it in nato phonetic, bravo alpha charlie, which means flip switch 2, then 1, then 3.
- wiring: connect them red, blue, yellow (the pod manual shows which symbol each one goes to).

the 3d version uses the same ideas but its deck sign reads deck 7, so there the pin is 56.

## the 3d pipeline

- `render3d/scenes/*.js` one three.js scene per room (quarters, control, pod, title, space, podsprite), `kit.js` is the shared materials, textures and post, `podmodel.js` is the lifeboat
- `node render3d/render-all.js` renders every scene into `render3d/out` (needs `npm install` inside `render3d/` and chrome installed)
- every render also records where each named 3d object lands on screen, so the figma hotspots line up with the props
- `node tools/build-assets.js` packs the renders (`assets/`) and regions into `src/assets.js`, then `node tools/build-plugin.js`

## layout

- `src/` the figma builders: `rooms.js` `puzzles.js` `closeups.js` `endings.js`, plus the shared bits `helpers.js` `images.js` `art.js` `ui.js` `flow.js`, and `wire.js` for the prototype links
- `site/` the three.js web version (the live 3d game)
- `tools/` build scripts and the offline test harness
- `assets/` the rendered images
- `web-prototype/` the first html version of the puzzle logic

## testing without figma

`node tools/mock-figma.js [outDir] [--sheet frameKey ...]` runs the plugin against a tiny fake of the figma api, plays through the prototype links (the solution, wrong pins, wrong wires, hints, close-ups) and can render frames to png (`HOT=1` outlines the hotspots). needs `npm install` inside `tools/` once.

## oxy, the mascot

a little face only buddy with four moods (idle, happy, worried, dizzy). `node tools/mascot.js` generates `assets/mascot/*.svg` plus the data files the website and the figma plugin both use. he greets you on the title screen, helps in the mission checklist and the hint cards, and reacts on the win and lose screens.
